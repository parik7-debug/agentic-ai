# API Results (Sample Run)

This file captures sample results from the Document Q&A API running locally in Docker (`http://127.0.0.1:8080`) using the sample document [resources/AP_Micro_Unit1_Quizlet.txt](resources/AP_Micro_Unit1_Quizlet.txt).

## 1. Health check

**Request**
```powershell
curl.exe http://127.0.0.1:8080/health
```

**Response**
```json
{
  "status": "ok"
}
```

## 2. Upload document

**Endpoint:** `POST /documents` (`multipart/form-data`, field name: `files`)

**Request**
```powershell
curl.exe -X POST "http://127.0.0.1:8080/documents" `
  -F "files=@resources\AP_Micro_Unit1_Quizlet.txt"
```

**Response** (`201 Created`)
```json
{
  "upload_id": "a387550663354346bbc7c57c01a4bccb",
  "files": [
    "AP_Micro_Unit1_Quizlet.txt"
  ],
  "chunks_indexed": 52
}
```

## 3. Ask a question

**Endpoint:** `POST /questions` (`application/json`)

**Request body**
```json
{
  "question": "What is opportunity cost?",
  "upload_ids": ["a387550663354346bbc7c57c01a4bccb"]
}
```

**Request (PowerShell example)**
```powershell
$body = @{
  question   = "What is opportunity cost?"
  upload_ids = @("a387550663354346bbc7c57c01a4bccb")
} | ConvertTo-Json -Compress

Invoke-RestMethod -Uri "http://127.0.0.1:8080/questions" -Method Post `
  -ContentType "application/json" -Body $body
```

**Response** (`200 OK`)
```json
{
  "answer": "Opportunity cost is the value of the best alternative foregone when a choice is made (the return you could have earned)."
}
```

## Notes

- Results were captured from a live local run of the API container; answers are generated by the configured Gemini model and may vary slightly between runs.
- Uploaded data and indexed chunks are stored in the container’s configured directories (ephemeral in the default Docker demo setup). The `upload_id` shown above is specific to this run.
- The upload and question steps require a valid `GEMINI_API_KEY` because embeddings and answer generation are performed via Gemini.
